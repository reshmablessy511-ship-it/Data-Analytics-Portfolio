# Dynamic Demand Forecasting & Inventory Optimization System

## Project Overview
This project focuses on predicting future product demand using historical sales data to help businesses make better inventory decisions.

## Business Problem
Businesses face challenges such as overstocking and stockouts due to changing customer demand, seasonal trends, and promotions.

## Objectives
- Forecast future product demand.
- Analyze historical sales patterns.
- Compare forecasting models.
- Support better inventory planning.
- Reduce excess inventory and product shortages.

## Technologies Used
- Python
- Pandas
- NumPy
- SQL
- Machine Learning
- Time Series Forecasting

## Algorithms
- Moving Average
- Naive Forecasting
- Seasonal Naive Forecasting
- XGBoost
- Prophet

## Project Status
Currently developing and evaluating forecasting models.
