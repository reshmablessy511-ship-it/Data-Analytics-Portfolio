# Early Warning and Monitoring of Wildfire

## Project Overview
This project aims to develop an IoT-based system for early detection and monitoring of wildfires.

## Objectives
- Detect possible wildfire conditions.
- Monitor environmental parameters.
- Provide early alerts when fire-related conditions are detected.
- Support faster emergency responses.

## Technologies Used
- ESP32
- Arduino IDE
- IoT
- ThingSpeak
- Embedded Systems

## Hardware Components
- ESP32
- DHT11 Sensor
- MQ-6 Gas Sensor
- Flame Sensor
- IR Sensor
- Ultrasonic Sensor
- Soil Moisture Sensor
- Rain Sensor
- Water Level Sensor
- 16x2 LCD with I2C

## Project Type
Academic IoT Project
